# 血管形态定量指标（flags b6）

2026-10-07 新增。在 AI 血管掩膜上计算一组形态指标，随统计块回传，并回传一幅“形态骨架”视图。
仅用于工程教学与算法演示，不作临床诊断依据。

## 1. 指标与定义

代码：`src/vessel_morph.c/.h`（板端 PS，C99）。独立参考：`ai/net/vessel_morph_ref.py`（NumPy + SciPy）。

| 指标 | 定义 |
| --- | --- |
| 血管像素 | 掩膜（logit ≥ 本帧门限）去掉 8 连通面积 < 20 px（按 512 尺度缩放）的小块后的像素数 |
| 总长度 | Zhang-Suen 细化得到单像素骨架；长度 = 正交链接数 + √2 × 斜向链接数（两点间已有正交路径时不计斜向） |
| 平均管径 | 血管像素 / 总长度 |
| 分支点 / 端点 | 骨架像素的交叉数 CN = ½Σ\|P_k − P_{k+1}\|：CN = 1 为端点；CN ≥ 3 为分支像素，其 8 连通簇算一个分支点 |
| 段数 | 骨架去掉分支像素及其 8 邻域后的 8 连通块数 |
| 迂曲度 | 只取两端点、弧长 ≥ 10 px 的段：Σ弧长 / Σ弦长（直线 = 1） |
| 分形维数 | 盒计数：盒边 2、4、…、≤ min(w, h)/4，ln N 对 ln s 做最小二乘，斜率取负 |
| FOV 内密度 | 视野（亮度 (77R+150G+29B)>>8 > 20）内的血管像素占比，另给左上 / 右上 / 左下 / 右下四个象限 |

分析网格：整图帧 = AI 分辨率（512 档就是 512×512）；ROI 帧 = ROI 框本身（全分辨率）。
上位机把长度、管径换算成 512 尺度的像素显示。

## 2. 协议

- 请求：控制头 flags **b6**（`FLAG_MORPH = 0x0040`），**必须同时带 b3**（统计块）。
- 回传：统计块之后紧跟 64 字节指标块（u32 小端 ×16：magic `MRP1`、版本、网格宽高、血管像素、FOV 像素、长度×10、
  管径×100、分支、端点、段数、迂曲度×1000、分形维数×1000、密度×1000、四象限密度×1000（两两打包）、PS 用时 µs）；
  图像流最后多一幅形态骨架视图（血管半透明红、骨架白、分支点红点、端点青点）。
- 能力协商：统计块 **version 4** 起认 b6；上位机据此决定等不等指标块和视图，老板端不会让它空等。

## 4. 指标靠不靠谱（20 张 STARE，开发评估）

以两位专家（VK 对 AH）之间的差异为参照尺度：

| 指标 | r(模型, AH) | r(VK, AH) | 模型 vs AH 平均相对偏差 | VK vs AH | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| 总长度 | 0.89 | 0.80 | 15.2% | 39.2% | 可用 |
| 分支点数 | 0.83 | 0.77 | 31.3% | 107.2% | 可用 |
| 分形维数 | 0.74 | 0.73 | 4.0% | 6.2% | 可用 |
| FOV 内密度 | 0.78 | 0.78 | 28.8% | 43.1% | 可用（模型偏高） |
| 迂曲度 | 0.65 | 0.74 | 1.2% | 1.0% | 基本可用 |
| 平均管径 | 0.16 | 0.65 | 23.7% | 8.4% | **不可靠**：模型血管偏粗（3.50 vs 2.94 px） |
| 端点数 | 0.36 | 0.85 | 27.1% | 81.1% | **不可靠**：模型掩膜的细血管容易断开 |

两位专家对细血管的标注差异很大（VK 的总长度比 AH 长 39%），所以“模型 vs AH”的偏差要和这一列对比着看。
完整表格与逐图数值：`docs/vessel_morphology_metrics_eval.md` / `.json`。20 张图都参与过模型选择，这是开发评估。

## 5. 现状与后续

- **当前在 PS 上计算**（不动比特流，随 `src/` 一起部署）。PS 用时由板端实测后随指标块回传，未上板前没有数字。
- **迁到 PL 的计划**：去小块（连通域）、Zhang-Suen 细化、交叉数、盒计数都是 3×3 窗口或逐像素的流式运算，
  `vessel_morph.c` 即可作为 HLS 版本的参考；A 已有的 3×3 形态学 IP（`medical_fpga/hls/morphology`）可复用其行缓存结构。
  受限于：本机只有 Vivado / HLS 2023.1，而现有系统用 2025.2.1 构建；PL 只剩 24 块 BRAM；需要上板验证。
- 门限滑条在本地改门限时，形态指标仍是板端本帧门限下的值（界面上注明门限）。
