# 血管形态指标：模型掩膜 vs 人工标注

由 `ai/net/vessel_morph_eval.py` 生成。指标定义见 `src/vessel_morph.h`；计算用 `ai/net/vessel_morph_ref.py`（与板端 C 实现逐项一致，见 `vessel_morph_check.py`）。

- 样本：STARE 20 张，512×512；模型掩膜为部署版整数模型输出（logit ≥ −3，与实板逐字节一致的那份）；
  AH、VK 为两位专家标注（最近邻缩放）。
- “VK vs AH” 是两位专家之间的差异，作为参照：模型与 AH 的差距若接近它，说明指标在模型掩膜上可用。
- 20 张图都参与过模型选择，这是开发评估，不是独立测试；指标仅用于工程教学与算法演示，不作临床诊断依据。
