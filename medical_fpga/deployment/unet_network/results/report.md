# 整网 HLS C 仿真验证结果

范围：unet_conv 与 unet_eltwise 两个 HLS 算子按 `vectors/network.txt` 逐层执行 30 个节点，在 C 仿真中处理全部 STARE 图像。不是 RTL 仿真，也不是板上结果。

- 图像数：20；与 lwnet 整数参考逐值一致：20/20。
- 血管判定：`final >= -3`（对应概率阈值 0.4196）。
- 平均 Dice（AH 标注，512×512 全画布）：全部 0.761782，FP32 0.763361。
- calibration（8 张）：HLS 0.779411，FP32 0.779824。
- holdout（12 张）：HLS 0.750030，FP32 0.752385。

全部 STARE 图都参与过 lwnet 的模型选择，这里的 Dice 属于开发验证，不是独立测试或医学有效性结论。
