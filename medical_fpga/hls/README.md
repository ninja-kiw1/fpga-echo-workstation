## 接口与串联

三个顶层均以 AXI Master 读写 DDR，用 AXI-Lite 配置；输入输出应使用不重叠缓冲区，ARM 负责启动、等待和必要的缓存同步。当前不需要额外串接 AXI DMA。

后续可以用 DDR 中间缓冲串联滤波、阈值化和形态学。形态学输入的非零值全部视为前景，所以必须先获得二值掩膜；是否采用滤波和开闭运算，需要与 B 根据模型输入和精度确定。

A 负责算法、IP 与参考输出，C 负责系统连接和 ARM 调用，B 确定模型输入输出及量化约定。三个基础处理模块不等于已经完成赛题的智能分析和连续交互显示要求。
