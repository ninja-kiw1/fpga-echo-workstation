## 结论

- **零额外模型**：直接用板上左室掩膜（程序 16 + 关键帧调度 + 板上跟踪，与 EF 是同一套）在每拍舒张末 / 收缩末算 6 个心尖四腔节段的面积变化。没有新网络，也不额外占用 PL。
- **TEST（65 段，心梗 37 段，只评一次）**：

  | 层级 | 灵敏度 | 特异度 | F1 | AUC |
  | --- | ---: | ---: | ---: | ---: |
  | 节段（390 个） | 0.853 | 0.595 | 0.607 | 0.780 |
  | 整段（任一节段心梗 = 阳性） | 0.757 | 0.857 | 0.812 | 0.897 |

  DEV 5 折交叉验证：节段 0.777 / 0.629 / 0.542 / AUC 0.757；整段 0.607 / 0.878 / 0.716 / AUC 0.794。TEST 比 DEV 好，主要是抽样波动（65 段）。
- **实话**：整段层面，**单靠 EF 就能分出心梗录像**（TEST 上 AUC 0.90，DEV 0.83）。节段分析的价值主要在**指出哪一段**，不在提高"有没有"。各位置 AUC 0.73–0.84（TEST）。
- 对照文献：HMC-QU 原作者在 A4C 上专门训练的方法（Degerli 2021、Kiranyaz 2020）整段灵敏度约 0.86、F1 约 0.8x；这里是零额外模型、零训练的板上规则，数字可比但不宜直接比较（划分不同）。

## 3. 方法（`wm_proto.py` → C：`tcp_image_rx/src/cardiac_ext.c`）

- 每拍用舒张末（ED）掩膜定坐标：主轴（心尖 = 上端）、u = 0（基底）… 1（心尖）、过 ED 质心的主轴两侧（左 = 间隔，A4C 画面上左室在右侧）。区域 = u 的三等分 × 两侧。
- 收缩末（ES）掩膜的像素按同一 ED 坐标分区；fac_k = 1 − A_ES,k / A_ED,k，按拍平均。
- 节段提示：z_k = (fac_k − μ_k) / σ_k（μ、σ = DEV 非心梗节段），−z_k ≥ t_seg 时"提示运动减低"。
- 整段提示：logistic(w0 + w1·(EF − 50)/10 + w2·mean z + w3·min z) ≥ t_rec（EF = 板上校准 EF）。
- 比较过的方案（DEV 5 折，`wm_proto*.py`、`results/dev_cv*.json`）：面积变化 vs 平均内移 / 心长；绝对 vs 相对自身中位数；6 个门限 vs 共用门限；最差节段 / 平均 z / EF / logistic。选择规则事先定为"整段交叉验证平衡准确率最高"，选中 logistic（关键帧档）。相对自身中位数的版本明显更差（AUC 0.5–0.7）。
- C 与 numpy 原型：PCA 用闭式解，特征最大差 0.002（个别边界像素），交叉验证数字不变。参数 `results/wm_params.json`（`fit_wm.py`），窗口配置 `tcp_image_ui/echo_heart_config.json`（`make_heart_config.py`）。

## 5. 局限

- HMC-QU 只有一个中心的低质量录像，65 段测试，置信区间宽。
- 节段由面积三等分近似，不是逐像素心肌追踪；心尖帽不评；侧壁基底段在部分录像里被扇区边缘截掉。
- EF 本身已带来大部分整段区分能力；节段提示的特异度低（0.60），只适合"提示复核哪一段"。
