## 序列（F3 序列跟踪、F4 射血分数用）

同样三位病人的二腔心、四腔心 ED→ES 半周期序列，每个文件夹一段：`frame_000.png` 起按顺序是各帧（原始分辨率 8 位灰度），
第一帧和最后一帧另有 `_gt.png`（专家标注的左心室腔，仅供对照，上位机载入时跳过），`sequence.json` 写像素间距和帧率。

同一位病人的二腔心、四腔心两段合起来可以在 F4 里算双平面射血分数；`ef_ref` 是 CAMUS 给的参考 EF（由专家标注按官方方法算出）。
