## 1. 移植（只在主机上做）

| 部分 | 文件 | 内容 |
| --- | --- | --- |
| 算法 C | `src/strain.c/.h`（不依赖板子，服务端和主机测试程序共用）+ `src/bm_sad.c/.h`（从 `strain/step2/` 原样拷入） | 128 掩膜 ×4 → 心肌 = epi ∧ ¬lv → 最大 8 连通块 → Zhang 骨架（skimage 0.25 的查表法）→ 最长路径（两次 Dijkstra，np.argmax 取第一个）→ 5 点滑动平均 + 每 3 mm 重采样（照 np.convolve / np.cumsum / np.linspace / np.interp 的运算顺序）→ 坐标 ×256 四舍六入五成双 → 逐帧 `bm_track_line`（512 档、±6、k = 9、V 拟合；板上 NEON neon2）→ 每帧 5 点滑动平均后线长 → GLS-like(t) = L(t)/L(0) − 1；ES 值另给 + TRAIN 偏移 −3.81 个百分点（`calib_train.json`，记 sha256） |
| Python 参照 | `strain/step3/strain_port.py` | 不用 scipy / skimage 的逐行移植（像 `simpson_port.py`），SAD 核仍走 `bm_sad.dll` |
| 主机核对 | `strain/step3/harness_strain.c` + `compare_host.py` | VAL 100 段：C 对 `strain_port.py` 的中层线像素、块位置、每帧追踪坐标（Q8）、曲线**全部逐位相同** → `STRAIN_HOST_PASS`；再拿 `strain_port.py` 对 `track_val.py` 的最终方案：逐段 ES 值相同的段数、最大差，重算 VAL 偏差 / MAE（应复现 +3.71 / 4.19，偏移后 3.14；有差就逐段说明原因） |

浮点：`-ffp-contract=off`；线长 / 边权用 `sqrt(dx²+dy²)` 不用 `hypot`（板上 glibc 2.27 与 Windows 的 `hypot` 末位可能不同），与 `track_val.py` 的差异在第 2 项里量化。
已知风险：骨架有小环时，scipy Dijkstra 的前驱选择可能与 C 不同（只影响 `strain_port` 对 `track_val` 的那一项，不影响 C 对参照的逐位）。

## 2. 板端病例任务 `strain`（`src/job_strain.c`，`JOB_STRAIN = 7`）

- **请求**：参数 = f64 sx、f64 sy（512 网格上每像素 mm，PC 由原图尺寸和像素间距算好）+ 选项；数据 = T 帧 512×512 u8（上位机 512 帧的 R 通道，第 0 帧 = ED、最后一帧 = ES，CAMUS 半周期序列）。约 4.7 MB / 切面（18 帧）。
- **板上**：ED 帧 [::4, ::4] → **PL 跑模型 2（F1 echo_lv）和程序 18（camus_epi）** → 阈值 ≥ 1 + 最大 4 连通块 + 填洞**默认在 PL pp_layer 上做**（按 §9.57 的决定；flag 改用 PS，交叉核对）→ PS 提线 + NEON 追踪 → 结果。
  128 上清理再 ×4 与原型在 512 上清理应完全等价（4 连通在最近邻放大下不变），主机上先穷举验证。
- **回复**：RESULT JSON（曲线、ES 原始值、ES + 偏移、峰值、点数、出界点数、耗时：U-Net / pp / 提线 / 追踪合计和每对帧、`pl_split`）+ BLOB（追踪点 int32 Q8 T×n×2、中层线、心肌掩膜位图）。
- caps 的 jobs 加 `"strain"`，server 版本号按 §0 定。上位机 `jobs.py` 加 `strain()`。
