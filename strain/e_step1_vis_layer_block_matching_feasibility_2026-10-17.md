# 部分 E 第一步：现有 vis_layer 能否"每块调用一次"做 SAD 块匹配（2026-10-17，只做软件 / C 仿真，没碰板子、没构建比特流）

**结论：能，但有限制（yes-with-limits）。E 不需要 r3。**

- **能**：f150 里的 vis_layer **不改一行**就能做逐块 SAD：每个追踪块调用一次 REG（128 小图 + "掩膜图块"技巧，见 §1），
  每个候选位移的 SAD **只算模板内的像素、与独立参考逐位相同**（C 仿真 308 块 × 3 种搜索 = 924 次调用、121 660 个候选，**0 处不同**）。驱动也不用改（`vis_reg()` + 自己的代价表）。
- **限制**：
  1. **慢**：REG 每个候选都要扫完整张 128² 图块（4 096 拍，有用的只有 16² = 1.6%），f150 上**每个候选 27.1 µs**。±4 全搜索一块 ≈ 2.3 ms，±6 ≈ 4.7 ms；
     一帧 74 块（中层一条线、3 mm 间距）≈ 0.17–0.35 s，**比 A53 单核 NEON 估计慢几百倍**。
  2. **三步搜索在斑点图上不可靠**：已知平移 (−3, +2) px，三步只找对 94/120，全搜索 120/120 → 只能用全搜索。
  3. **PL 自己选的"最优"不能用**：它按 SAD / 整张图块的重叠面积比较，308 块里 5–6 块和"原始 SAD 最小"不同 → 最优位移由 PS 从每个候选的记录里取（记录里的 SAD 是精确的）；亚像素用 PS 抛物线拟合，或 PL 的 ¼ 像素细化（它围绕 PL 自己的最优点，同样有 ~2% 偏差）。
  4. 模板像素要右移 1 位（0..127），因为 128..255 被用来"屏蔽"背景。
- **建议**：E 的追踪主体放在 **PS（NEON / C）**——一帧 < 1 ms 量级，相对整条心超流程可以忽略；vis_layer 只作**可选的"PL 复核 / 演示模式"**
  （例如 6–12 个节段中心块在 PL 上追踪，每帧 15–30 ms，可以和 PS 的 SAD 表逐位对照——这本身就是一条"PL 与 PS 结果逐位一致"的证据）。
  **不建 r3**：就算加多块模式，4 路的 PL 也只和纯 C 差不多快，16 路才约等于 1 个 NEON 核（§4），换不来值得一次比特流（约一天 + 冻结前名额）的收益。

## 1. "掩膜图块"技巧（不改 PL）

一块一次调用，用 n = 128 的 REG 帧当"图块"：

| 内容 | A（参考帧） | B（被搜索帧） |
| --- | --- | --- |
| 图块中心 16×16（模板） | 第 t 帧像素 >> 1（0..127） | — |
| 模板外扩 M = 8 的窗口（32×32） | 255 | 第 t+1 帧像素 >> 1（0..127） |
| 其余 | 255 | 0 |

代价表 `tab[d] = d (d < 128)，0 (d ≥ 128)`。A 的背景是 255，B 里任何值（内容 ≤ 127、背景 0、或双线性混合 ≤ 127）都使 d ≥ 128 → 代价 0；
模板像素在 |位移| ≤ M − 1 时总落在 B 的窗口内容里 → d ≤ 127 → 代价 = |差|。所以**每条记录的 SAD = 模板上的 SAD**（含 ¼ 像素双线性，公式与 PL 相同）。
窗口外越界的像素 PL 本来就按 0 代价处理。搜索半径 ≤ 15（n = 128 的上限），模板可到 112 − 2M。

## 4. 每帧要多少块、多少时间

**心肌大小**（`blocks.py`，CAMUS VAL 200 帧专家掩膜，心肌 = epi − lv，= 程序 18 + F1 的输出口径）：中层线长 P50 **221 mm**（P5 170 / P95 267，骨架计数略偏长）、壁厚 P50 11.9 mm；
512 档像素约 0.36 × 0.27 mm。每条线 3 mm 间距 **P50 74 块**（P95 90），内 / 中 / 外三条线 222 块；2 mm 间距一条线 111 块。
**帧间运动**：半序列 P50 18 帧（10–33），左室边界每帧移动在 128 档 ≤ 1–2 px → 256 档 ≤ 2–4 px、512 档 ≤ 4–8 px（边界法向，偏下限）→ 256 档 ±4、512 档 ±6–8。
一例 GLS 要 A4C + A2C 两段，各约 17 对帧 → **约 34 对帧 / 例**。

| 方案 | 每块（16×16，±4 / ±6） | 每对帧 74 块 | 每对帧 222 块 | 每例（74 块，±4） |
| --- | --- | ---: | ---: | ---: |
| **A：现有 f150，每块一次调用（本文）** | 2.3 / 4.7 ms | **0.17 / 0.35 s** | 0.51 / 1.04 s | **≈ 5.7 s** |
| B1：r3 加"多块 + 窗口"模式，4 路（§5） | 50 / 103 µs | 3.8 / 7.8 ms | 11 / 23 ms | 0.13 s |
| B2：r3 多块 + 16 路 + 候选间无气泡 | 11 / 22 µs | 1.0 / 1.8 ms | 2.5 / 5.1 ms | 0.03 s |
| PS 单核 NEON（**估计**，60–100 拍 / 候选 @ ≤1.2 GHz） | 4–7 / 9–14 µs | 0.3–0.5 / 0.6–1.0 ms | 1–3 ms | 0.01–0.02 s |
| PS 纯 C（估计，约 NEON 的 1/4） | 16–28 / 34–56 µs | 1.2–2 / 2.5–4 ms | 4–12 ms | 0.04–0.07 s |

（B1 / B2 / PS 都还要加一次调用的固定开销：B 装两帧 256² 约 0.1 ms。PS 数字是估计，第二步开头在板上用 10 分钟的微基准确认。）

**读法**：A 能用但慢（每例几秒，适合"PL 复核几块"而不是整段追踪）；B1 ≈ 纯 C、B2 ≈ 1 个 NEON 核——**PL 在这种小、访存规整的运算上没有优势**，
因为 vis_layer 为了 LUT 只留了 4 路（0.6 G 像素 / 秒），而 A53 的 `uabal` 一条指令就是 8 路。要明显胜过 4 核 NEON 得上整块并行的二维 SAD 阵列（≥ 256 绝对差 / 拍，约 5–7k LUT），
那就要卷积退回 V9b（`ap` 慢 40–47 ms，伤主线），不划算。

## 5. 如果仍要 r3：具体改动清单（**不建议**；仅供决定）

从 `ai/bd/build_ai_sys_f_clk.tcl` 派生，只换 vis_layer IP；**PL 时钟按实际 `pl0_ref` 101.376 MHz → 152.15 MHz 约束**（HLS 周期 6.57 ns，构建后再按 101.376 复核）。

1. **新 op 3 `BM`**（`vis_layer.hpp` 字段表 + `visref.py` 规格）：f1 帧 n（128 / 256，A、B 每次调用只装一次）；f2 模板宽 | 高 << 8（4 的倍数，≤ 32）| 半径 R << 16（≤ 7）| 亚像素 << 24；
   f3 块数 K；f4 A、f5 B、f6 代价表、f7 块表（每块 64 位：模板左上 ax, ay + 搜索中心 bx, by，各 16 位）、f8 输出。所有偏移、每块的窗口都先校验，非法返回 4、不写任何字（与 REG 同规则）。
2. **`reg_eval` 加窗口**：起点 (ax, ay)、宽 / 高，用行 / 列计数器替换 `it >> lg`；ax 按 4 对齐，复用现有 4 路双线性和取数（B 的两字窗口对 LN ≤ 16 都够）。
3. **每块搜索**：复用 PH 循环（全搜索 + 可选 ½ → ¼ 像素），窗口在图内时重叠面积恒为模板面积 → 现有 `better()` 的比较就等于原始 SAD 比较（不再有 §2 的偏差）。
4. **输出**：每块 2 字：最优 (qx, qy)、SAD、状态 + 整像素最优点 3×3 邻域 SAD（给 PS 做抛物线亚像素）；可选全部候选记录（调试）。
5. **（B2 才要）** LN 4 → 16，候选循环与像素循环合并成一个流水（去掉每候选 29 拍收尾）。
6. 验证门槛：`visref.py` + `gen_vectors.py` 加 BM 向量；现有 592 向量全过；C 仿真 + **协同仿真**（硬门槛）；整板构建；按 `board_acceptance_f` 派生全套验收 + 新的 BM 向量；驱动 `vis_bm()` + 服务端新版本。

| 估计 LUT（相对 f150 的 59 801，84.75%） | ΔLUT | 合计 | 要不要退 V9b |
| --- | ---: | ---: | --- |
| B1（多块 + 窗口，4 路） | +0.6–0.9k | ≈ 85.6–86.0% | 不要 |
| B2（+ 16 路 + 无气泡） | +3.5–4.5k | ≈ 89.7–91.1% | 152 MHz 下布线有风险，可能要退 V9b（−9.7k） |

估计依据：v4 分项 REG 计算核 0.55k / 4 路（含双线性和 4 份 LUTRAM 代价表）；v1 的 16 路版整核 13.0k vs v2 8.9k；B1 新增的只是描述符解析、块循环、窗口计数器和每块输出。
