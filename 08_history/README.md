## 容易踩的三个前提

读这些文档时会反复撞到这三件事，先记住可以省很多困惑：

1. **PL 与 PS 必须配套换。** P7 起的比特流删掉了 `img_proc` 整块，而 11-13 那版服务端启动要读 `0xA0000010` —— 读到就是 SIGBUS。反过来，P14/P15 的服务端会往 conv 的 `0xC0~0xE8` 写扇形寄存器，f150nv 里没有这些寄存器，写了会把板子挂死。**换版本前先 grep 服务端读哪些 PL 地址。**

2. **标称时钟不等于板上时钟。** Vivado 报的 WNS 是按约束（150 MHz）算的；这块板的 `pl0_ref` 由 BOOT.BIN/FSBL 定死在 **101.376 MHz**，对应实钟 **152.15 MHz**。所以「标称 WNS +0.015」可能对应「实钟 −0.073、25 个端点违例」—— P7d 就是这么没过验收的。凡是谈时序，一律问一句"是按哪个时钟签的"。

3. **CLB 不是 LUT 的函数。** 名义 LUT 66.7% 的时候 CLB 已经 95.77%（只剩 373 个 slice），装箱密度 5.57/8。估一次改动的收益，边际换算率只有 **≈7~11 LUT/CLB**，不是 5.7。
