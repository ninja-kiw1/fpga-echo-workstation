# 事件时间线只留心拍（2026-11-19）

## 需求

「事件时间线」原来有三栏：**心拍**（每拍一段 + 该拍 EF）、**关键帧**（蓝 = PL 分割 / 灰 = PS 跟踪帧）、
**纠错**（橙 = 人工纠错 / 浅橙 = 跟着重算）。后两栏只在核对"关键帧调度"和"点击纠错"时有用，
日常看片子是噪声 —— 按要求删掉，只保留心拍一栏。**上位机（PC 版）和板载程序一起改**。

## 改法

板端版是 `03_build/make_board_ws.py` 从 PC 版生成的（PC 版是唯一来源），所以只改 PC 版再生成，
不手工碰板端文件。共五处：

| 位置 | 改动 |
| --- | --- |
| `EchoView._draw_timeline` | 删掉「关键帧」「纠错」两个行标签、两段竖线循环、顶部那句"蓝 = PL 分割的关键帧（约 18%），灰 = PS 跟踪帧"提示、底部图例；心拍条整体下移到 y 7–27，EF 文本居中 y=17 |
| `CW, CH, TH` | 时间线画布高度 **92 → 38**（只剩一行，不再留 54 px 空白） |
| `EchoView._draw_cursor` | 时间线那条光标终点 `TH-20` → `TH-3`（否则会停在心拍条中间） |
| 面板副标题 | "关键帧与跟踪帧分开显示，方便核对 ED / ES" → "每拍一段（颜色交替），段内标该拍 EF；方便核对 ED / ES" |
| 模块头说明 | "事件时间线（心拍 / 关键帧与跟踪帧 / 纠错帧）" → "事件时间线（只画心拍，11-19 起关键帧 / 纠错两栏已删）" |

`make_board_ws.py` 里两处**锚点跟着撤掉**：`TIMELINE_OLD` / `TIMELINE2_OLD` 改写的正是被删掉的那两句
时间线文字（板上画布只有 392 px，11-18 曾经为溢出 30 px 缩短过），PC 版里已经不存在，留着会直接
`SystemExit`；`CURSOR_OLD` 的锚点同步成 `TH - 3`。

**没动的**：关键帧 / 纠错这两类帧号本身照旧可见 —— 帧标题仍写"关键帧（PL 分割）/ 跟踪帧（PS 块匹配）"
和"人工纠错 / 纠错后跟着重算"，容积曲线上仍画纠错帧的橙点，延迟图下面的关键帧刻度也还在。
这次只删时间线那两栏。

1. **无头结构检查**（新脚本 `04_verify/verify_timeline_beats_only.py`，塞假 tkinter + 记账假画布，
   按值调用 `_draw_timeline` / `_draw_cursor` 后逐项断言）：
   PC 版与板端生成版都 **TIMELINE PASS**。时间线只剩 6 个图元
   `['text','rect','text','rect','text','line']`，文字 `['心拍','60%','55%']`，
   两条心拍矩形 y 7–27，光标 `(line, 25, 6, 25, 35)`；旧栏位的 31/37/43/49/55/69 六条竖线一条都没有。
2. **板端真跑**：`smoke.py` **SMOKE_DONE**（快照 / 关键帧 / 现场三模式 + 平台扩展都建得起来），
   主窗口 1561×1087（比例程里矮了 54 px，正是 TH 收掉的那 54）。
3. **板端真画 + 截图**（新脚本 `/data/ws2026/board/tlprobe.py`，真 Tk 画布灌假逐拍结果后 `_draw_timeline`）：
   `VIEW 'EchoView'  TH=38`、`TL_BOX 535 0 **392 × 38**`、`TLPROBE_DONE`。
   截图里「事件时间线」只剩一行：`心拍 | 60% | 55%`，黄色光标竖线穿过这一行，下面直接接「全心」卡片。
4. 板端部署后 `md5sum /data/ws2026/app/workstation.py` = `ec8757f3ade4110e6d2fce0970f8d927`，
   与本地生成件一致；上传前把板上的旧件逐行 diff 过一遍，**差异只有上表那五处**（22 行删 / 13 行增），
   说明板上原本与 PC 版同步（旧 md5 `835b14d6…`，即 11-19 板端同步那一版）。

## 保留意见

- 板上界面**开机不自启**（11-18 定的），这次没有改；要看效果从桌面图标 / 菜单进。
- 本次只改显示，不动任何调度或算法：关键帧调度、EF、质量灯、全心扩展的计算一行没碰。

  那两帧其实是从容积曲线取的帧号（`res->beats[k].ed/es`），可能落在跟踪帧上。要改措辞另开一笔。
