# ② 算子编译器：权重即指令（2026-10-09，**已上板验收**，v5.5）

**一句话**：把经典图像算子写成表达式，自动编译成板上那张**固定 30 节点 U-Net** 的一套权重，比特流不变。
这套权重和学出来的模型一样放进模型库，按帧切换，并在 HLS 位级模拟器和板上逐位验证。
同一颗 PL 引擎，既跑训练出来的模型，也跑编译出来的经典算法。

## 原理

引擎里全分辨率的那条路径：5 层“3×3 卷积 → ReLU → BN”，每层最多 8 个通道，加上最后的 1×1 线性输出层；下采样那半边的输出在拼接处乘 0，不起作用。
因此能表达的是 **11×11 邻域内的分段线性算子**：线性滤波，以及由 ReLU 拼出的 |x|、max、min、截断、中值等。

编译器（`ir.py`、`compiler.py`）：
1. **IR** 只有四种原语：输入通道、逐点线性组合、3×3 卷积、ReLU。`abs_`、`max_`、`min_`、`clip`、`median3` 都由它们精确拼出。
2. **区间推断**：每个值都算出上下界（输入在 [0,1]，零填充也计入）。下界 ≥ 0 的值穿过 ReLU 层不变，只占 1 个通道；有正负号的值要拆成 relu(v)、relu(−v) 两个通道。
3. **调度**：每个 ReLU 放到它的参数可用的下一层；线性部分折进下一层的卷积；需要更晚用到的值自动插入“搬运”通道。
4. **边界精确**：两次 3×3 卷积不合并成 5×5，带常数项的值进卷积前先落成真实通道，所以零填充和参考在图像边缘也逐像素一致。
5. **量化**：
   - 量化范围用编译器算出的区间上界，**任何输入都不会溢出**；
   - 中间层用 INT16，输出层用板端要求的 INT8；
   - 每个算子声明数学上成立的输出范围，输出层偏置减去范围中点，把 int8 的正负两半都用上，[0,1] 范围的输出可达 1 LSB = 1 个灰度级。
6. **量化锚点**：同一通道里系数比例对不上时，在一个恒为 0 的空闲输入通道上放一个锚定权重，让量化器选出能把所有系数都量化成整数的刻度。浮点结果完全不变，量化误差消失。
7. 卷积核用“int8 友好”的整数比例，例如模糊核取 (32, 64, 127)/511，直流增益严格为 1。

## 板端：模型库 + 多程序流水线（v5.5）

- 8 个算子程序进模型库，占 6–13 号。原协议的模型号只有 3 位、最多到 6 号，所以 **7 号以上通过紧凑帧调用**。
- **多程序流水线**：紧凑帧头的保留字节表示“额外程序数”，最多 3 个，每个程序 4 字节，内容是模型号、输入来源、放入哪个通道、门限。
  - 输入来源可以是原始帧，也可以是上一个程序的输出（偏移码 logit+128，对 [0,1] 范围的算子正好就是灰度图）；
  - 板上依次执行，所有输出一起回传。串联和分叉都能做。

**板上验收**（`verify_board_ops.py` → `board_check/acceptance_ops_v55.json`）：

| 检查 | 结果 |
|---|---|
| 8 个算子程序，各 11 张测试图（随机、结构图、全黑、全白、棋盘、心超三帧、眼底） | 板上输出与整数参考 **0 差异** |
| 串联：三帧中值去斑 → 心超分割 | 两个输出都 0 差异 |
| 分叉：一次请求同时出心超分割（中间帧）、运动能量、Sobel | 三个输出都 0 差异 |
| 吞吐（每个请求 1 / 2 / 3 个程序） | 25.2 / 12.8 / 8.6 次/秒（每个程序约 37.8 ms，PL 计算受限） |

STARE 20 张图，AH 人工标注，RGB 拉伸到 512，两种程序都在板上跑：

| 程序 | AUC（全画面） | AUC（视野内） | Dice（视野内） |
|---|---:|---:|---:|
| 学习模型（眼底 0 号，512 档） | 0.983 | **0.978** | **0.770**（部署门限） |
| 编译的线检测器，512 档 | 0.756 | 0.773 | — |
| 编译的线检测器，256 档（三档里最好） | 0.809 | **0.839** | **0.474**（门限 2 折交叉选定） |
| 编译的线检测器，128 档 | 0.755 | 0.822 | — |

结论：
- 我们的线检测器（4 方向、短线）明显不如学习模型。文献里 12 方向、多尺度的线检测器 AUC 约 0.96，我们受引擎深度和通道数限制，做不到那么多方向。
- 这里要证明的是**同一颗引擎换一套权重，就能在学习模型和经典算法之间切换**，量化结果也说明了为什么要用学习模型。
- 学习模型是 DRIVE 训练的冻结权重，STARE 以前被当过开发集，所以两个数都不是干净的测试集结果。
- 视野掩膜不是现成的，是按“红通道 > 25、取最大连通域、填洞”生成的。

## 局限

- 能编译的只有 11×11 邻域内的分段线性算子：不能做乘法（比如两个通道相乘），也不能做全局运算（比如直方图）；深度 5 层，每层 8 个通道。
- 输出只有 8 位，范围要事先声明。
- 512 档每个程序 565 ms，由 PL 计算决定。
