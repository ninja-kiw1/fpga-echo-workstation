# 第一阶段 U-Net 整数参考规范（开发版 v2）

更新：后续混合位宽方案通过了开发留出平均精度门槛，当前 HLS 候选见 `mixed_precision_spec.md`。本文保留全 INT8 v2 的数学规则与历史结果。

该规范对应 `int8_reference.py` 和 `results/stage1_int8_v2/quant_plan.json`。
目前能运行、可逐值复现，但精度门禁未通过，不应直接视作最终硬件规格。

## 数据与校准

- 模型：原 W-Net 的第一阶段，RGB 512×512。原始预训练参数不变。
- 数据布局 NCHW，批量 1；输入 UINT8，范围 0..255，scale=1/255，zero-point=0。
- 图像直接双线性缩放至 512×512，保持 RGB；标注最近邻缩放。浮点基线输入等价于 uint8/255。
- 中间张量及输出 INT8，采用窄对称范围 -127..127，zero-point=0（不使用 -128）。
- 随机种子 20260923，8 张校准；每个节点 scale=max(校准图浮点激活绝对最大值/127, 1e-10)。只观察图像，不使用标注决定 scale。
- 12 张开发留出图不参与范围校准，但全部 20 张已用于此前模型选择，且留出结果用于 v1/v2 比较。它们不是独立最终测试集。
- 本轮不搜索阈值，沿用 0.4196。ReLU、MaxPool 保持输入 scale；其余节点使用自身输出 scale。

## 权重量化与卷积

每输出通道 c：

```
Sw[c] = max(max_abs(W[c]), 1e-12) / 127
Wq = clamp(RNE(W / Sw), -127, 127)
Bq[c] = RNE(B[c] / (Sin * Sw[c]))
A[c,h,w] = sum(Xq * Wq) + Bq[c]
```

RNE 表示最近偶数舍入。权重导出 INT8，bias 导出 INT32，累加器 INT32。
普通卷积的权重为 OIHW；转置卷积为 IOHW，scale 仍按输出通道。
普通卷积 padding 按计划表补整数 0。转置卷积为 kernel=2、stride=2、padding=0、output_padding=0，不通过插值替换。

每层静态上界以输入类型范围乘权重绝对值之和，再加 bias 绝对值计算，并检查 <2^31；这是保守范围检查，非仅依赖样本不溢出。

## 舍入与重缩放

设浮点比例 r。选择整数 shift 在 0..30，使 `M=RNE(r*2^shift)` 在 INT32 范围内。
同一节点采用统一 shift；每通道/每分支可有不同 M。

```
qout = clamp(RNE_div_pow2(A * M, shift), -127, 127)
```

乘法及偏置相加用有符号 INT64，静态检查不溢出。禁止截断到 INT32 再右移。
负数的舍入通过绝对值商和余数实现：大于半步进位，恰好半步时向偶数进位，最后恢复符号。
例：±0.5→0，1.5→2，2.5→2，-1.5→-2。硬件必须复制此规则，不能用简单加半再右移代替。

## BN 与融合块

推理期 BN 的数学形式：`a=gamma/sqrt(var+eps)`，`b=beta-a*mean`。
v1 在 Conv、ReLU、BN 节点间量化；v2 移除 Conv 与后续 BN 之间的中间 INT8 落地，保持原顺序：

```
A = integer_conv_sum + Bq
R = max(A, 0)                 # 仅 Conv→ReLU→BN 主分支
R = A                         # Conv→BN shortcut 分支
M[c] = RNE(a[c] * Sin * Sw[c] / Sout * 2^shift)
O[c] = RNE(b[c] / Sout * 2^shift)
qout = clamp(RNE_div_pow2(R * M[c] + O[c], shift), -127, 127)
```

O 是 INT64，M 是 INT32；a 可以为负。不能把 BN 移到 ReLU 前，也不能将此称为普通 Conv→BN 权重折叠。
流水线实现时只需在累加与仿射阶段保留宽位数据，不要求把整帧 INT32 特征图放到 DDR。
最终输出卷积与两次转置卷积仍独立重缩放。

## 残差、拼接、池化

- Add：两路输入各按自己的 scale 生成比例 M，共用 shift；先在 INT64 相加 `q1*M1+q2*M2`，然后一次舍入、饱和。不能两路各舍入后再相加。
- Concat：两路分别重缩放到同一输出 scale，沿通道维按原模型顺序拼接，饱和到 -127..127。
- MaxPool：每通道 2×2 最大值、stride=2，保持原 scale。
- ReLU：有符号整数 clamp_min(0)，保持原 scale。

## 输出阈值

输出 scale=0.1017041844645823，zero-point=0。概率阈值 0.4196 等价于 logit > log(0.4196/0.5804)。
本参数包的整数判断是 **q >= -3**，已在所有图上核对与反量化后 Sigmoid 阈值的结果一致。
该整数阈值仅适用于这份参数包；换 scale 必须重新推导。显示概率时可用软件 Sigmoid，硬件二值分割无需计算它。

## 参考实现与交付边界

卷积在软件中使用 float64 执行整数操作数的乘加，每层检查绝对求和界 <2^53，并确认结果为整数；在此范围内表达整数和。重缩放、融合仿射、残差和池化按 INT64 运算实现。不是原生 INT8 加速后端，不提供 INT8 速度结论。

`check_integer_reference.py` 覆盖负数半步舍入、卷积 padding、转置卷积、负 BN 系数时的 ReLU 次序、饱和、残差一次舍入和池化边界。当前全部通过。

- `quant_plan.json`：30 个执行节点，包括 Input、17 个 ConvAffine、2 个转置卷积、2 个池化、5 个 Add、2 个 Concat、1 个输出卷积。
- `parameters.npz`：按节点名索引的权重、bias、乘数、offset、参考 scale。多字节整数数组指定小端；NPZ 是交换格式，不是最终 DDR blob。
- `im0002/golden_tensors/`：输入及每个执行节点的参考输出，NCHW；输入 uint8，其余 int8。
- `layer_errors.json`：全体图的饱和统计，以及 im0002 的逐层 MAE/最大误差。
- `summary.json`：精度、文件哈希、静态累加上界、门禁结果。

## 实测结论与下一步

12 张开发留出图平均 Dice：FP32 0.752385，INT8 v1 0.739702，INT8 v2 0.742002。
v2 平均下降 0.010383，仍超过事先暂定 0.01；不能四舍五入后宣称通过。
全部 20 张 v2 平均 Dice 为 0.754583，但不能用混入校准图的平均值替代留出门禁。
最差 im0324 从 0.592723 降到 0.510602，约下降 0.082121。

该图各节点最高饱和比例约 0.0034%，不能仅凭结果把掉点归因于大规模饱和。需要进一步做层敏感度分析，定位量化误差累积；优先依据校准图进行敏感度选择，再确认开发留出变化。可评估少数层提高位宽或量化感知微调，并明确新增资源成本。
在精度问题解决前，不冻结最终权重格式和 HLS 位宽。HLS 可以先验证与精度配置无关的卷积整数累加及舍入原语。
